## Eskiz

Eskiz 0.1.0 is licensed under MIT OR Apache-2.0 at your option. The licence texts are in `LICENSE-MIT`
and `LICENSE-APACHE`, shipped next to this file in every package.

Source code: <https://github.com/evarnimtb-netizen/eskiz-app>

This file lists the third-party software compiled into the default Eskiz build (`eskiz-app` with its
default features), with each licence text. It is generated with `cargo about` (`tools/gen_notices.sh`)
from `about.toml` and `about.hbs`; do not edit it by hand.

Per-target differences: the list below is the union of the Linux (x86_64-unknown-linux-gnu), Windows
(x86_64-pc-windows-msvc) and macOS (aarch64-apple-darwin) default builds. A few crates apply to one
platform only (for example `clipboard-win` and `error-code` on Windows, `objc2` crates on macOS,
`wayland` and `x11` crates on Linux). The Android build (`THIRD_PARTY_NOTICES-android.md`, shipped in the
APK) is generated for aarch64-linux-android with `--no-default-features --features android`.

## OpenH264

The default and distributed builds do not link OpenH264: MP4 export is off in 0.1.0, and
no H.264 code is included. A developer build with `--features mp4` compiles Cisco's OpenH264
(BSD-2-Clause) and must reproduce Cisco's notice and the H.264 patent licensing that applies to that
binary.
