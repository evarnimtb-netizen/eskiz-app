# Security policy

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue. Use the repository's [private vulnerability reporting form](https://github.com/evarnimtb-netizen/eskiz-app/security/advisories/new) (Security tab, "Report a vulnerability").

Include the version, your operating system, and steps or a file that reproduce the problem. Do not include files you are not allowed to share.

You can expect an acknowledgement within about a week. Eskiz is maintained by volunteers, so fixes are best effort; we will keep you informed and credit you if you wish.

## Scope

Eskiz 0.1 is a desktop app (and an experimental Android app) that runs on your own machine. The most relevant problems are bugs in the code that reads files you open: `.procreate`, PSD, brush and swatch files, ZIP containers, fonts, images, and 3D models. Crashes, hangs or memory problems on malformed files are in scope. Eskiz makes no network connections, so there is no server side to attack.

## Supported versions

Only the latest release receives fixes.
