# Text

## Adding text

Tap **Actions**, choose **Add**, then **Add text**. A text layer is placed at the center of the canvas, and you can type straight away.

While you type:

- **Arrow keys** move the caret, and **Shift** with an arrow key selects.
- **Home** and **End** move to the start and end of the line; with Shift they select.
- **Cmd+A** (Ctrl+A on Windows and Linux) selects all the text.
- **Backspace** and **Delete** remove text.
- **Enter** starts a new line.
- **Esc** finishes editing. The text stays as a text layer.

Each edit is part of one undo step, named **Add Text** or **Edit Text**.

## Edit Style

Tap **Edit Style** to open the style window for the selected text layer. It holds:

- **Font**: the system font, or a font you imported. **Search fonts** filters the list.
- **Size**, **Bold**, **Italic**, **Underline**, **Outline**, and **All caps**.
- **Color**, with **Use current color** to take the color in use.
- **Kerning**, **Tracking** (spacing across the line), **Leading** (spacing between lines) and **Baseline** (shift of the text up or down).
- **Justify**, **Left**, **Center** or **Right** alignment, and **Vertical** text.
- **Box width**: the width the text wraps to. Zero means the text does not wrap.

Changes are one undo step, named **Text Style**.

## Importing a font

Tap **Actions**, choose **Add**, then **Import font**. Type the path to a `.ttf`, `.otf` or `.ttc` file and tap **Import font**. Eskiz keeps a copy with its fonts, so the font is still there after you restart.

## Rasterizing

**Rasterize** in the style window, or **Rasterize Text** in the layer's menu, turns a text layer into ordinary pixels. The pixels are kept, but the text is no longer editable.
