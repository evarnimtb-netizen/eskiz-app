# Layers

Open the Layers panel from the top bar, or press **L**. Each layer is a card with a thumbnail. Drag a card up or down to change the order.

## Adding layers

Use the add button in the Layers panel to add a layer above the active one. **Duplicate** copies a layer. **Delete** removes it. **Rename** changes its name.

Tap a layer's menu to find its actions. Some of them apply only to some layers. A locked layer cannot be painted on, and the menu says "The layer is locked."

## Groups

**Group** puts the selected layers into a group. **Ungroup** takes the layers back out. A group has its own opacity, blend mode and mask, and it applies them to everything inside it. Drag cards into and out of a group to move them.

## Masks

**Add Mask** gives a layer or group a mask, which controls where it shows. **Remove Mask** discards the mask. Masks are always 8-bit, even on a 16-bit canvas.

## Clip to Layer Below

**Clip to Layer Below** clips a layer to the layer directly below it. The clipped layer shows only where the layer below has paint. The option is only available when there is a layer below.

## Lock transparency

**Lock Transparency** keeps a layer's transparent areas transparent. Painting then changes only the pixels that already have paint.

## Opacity and blend modes

Each layer has an opacity slider and a blend mode, set on its card. Eskiz offers 26 blend modes, from Normal and Multiply through Screen, Overlay and Difference to Hue, Saturation, Color and Luminosity. Opacity and blend mode of a group apply to the whole group.

## Locking

**Lock** stops changes to a layer. **Unlock** allows them again.

## Background

The **Background color** row at the bottom of the panel sets the paper color. The background is not a layer: it is shown under all layers, and it is the color JPEG exports are flattened onto.

## Guided Layer

**Guided Layer** switches on drawing guides for one layer, so its strokes follow the guides (see Drawing guides and reference).

## Text layers

A text layer is a layer whose text can still be edited. **Rasterize Text** turns it into ordinary pixels and drops the text (see Text).
