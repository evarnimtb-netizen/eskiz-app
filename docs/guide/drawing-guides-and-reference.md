# Drawing guides and reference

## Drawing guides

A drawing guide is a set of lines over the canvas that helps you draw straight, symmetrical or in perspective. Guides are not part of the picture: they are never painted or exported.

To show or hide the guide, open Actions > Canvas and switch **Drawing guide** on or off. To change it, tap **Edit drawing guide**. The editor has these settings:

- **Type**: **Grid**, **Isometric**, **Perspective** or **Symmetry**.
- **Grid size**, for a grid.
- **Vanishing points**, for perspective.
- **Mirror** and **Copies**, for symmetry: how the canvas is mirrored, and how many copies there are.
- **Center** of the symmetry.
- **Thickness** and **Opacity** of the lines, and the **Color** they are drawn in.
- **Show guide** turns the lines on or off.

Each document keeps its own guide settings.

## Guided Layer

Guided Layer makes the strokes of one layer follow the guide. Turn it on for a layer from the Layers panel. On that layer, a stroke near a grid, isometric or perspective line snaps onto it. With a symmetry guide, each stroke is mirrored into several strokes that together make one undo step.

**Lock after (px)** sets how close a stroke must come to a line before it snaps to it.

## Reference window

The reference window is a floating picture you can keep in view while you paint. Turn it on from Actions > Canvas, using the **Reference** switch. It shows either:

- the **canvas**, live, so it follows every stroke, or
- a **picture** you choose: type the path to a PNG or JPEG file in the field and tap **Show**.

The window can be moved and resized. It has its own zoom and pan, and **Fit** shows the whole picture. The reference window is never saved into the document and never exported.
