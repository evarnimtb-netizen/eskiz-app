# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). By taking part in the project's issues, discussions and pull requests you agree to follow it.

Please report unacceptable behavior privately through the repository's [security advisory form](https://github.com/evarnimtb-netizen/eskiz-app/security/advisories/new), mentioning that it is a conduct report, or to the maintainers by any private channel listed on their GitHub profiles. Reports are handled in confidence.
