# Privacy

Eskiz collects no data.

- It makes no network connections. It has no telemetry, no analytics, no crash reporting, no accounts, no update check and no advertising.
- Your artwork, brushes, preferences and the crash-recovery journal are stored on your own device, in Eskiz's data folder and in the files you save. Nothing leaves your device unless you copy or share a file yourself.
- If you report a problem, you decide what to attach. `eskiz --diagnose` writes a plain text report to a file in the current folder for you to read and paste yourself; it is never sent anywhere automatically.

If this ever changes (for example an optional update check), it will be off by default, described here first, and shown to you before anything is sent.
